🎫 Бронирования
6
GET /api/bookings
Получение списка бронирований
Требуется аутентификация

Query параметры:

Параметр Тип Описание
page integer Номер страницы для пагинации
POST /api/bookings
Создание нового бронирования
Требуется аутентификация

Форматы запроса:

Новый формат (массив мест):
{ "excursion_id": 123, "seats": [ { "seat_number": 1, "passenger_type": "adult", "with_entry": true, "customer_name": "Иван Иванов", "customer_phone": "+7 (999) 123-45-67" } ], "stop_id": 456, "weekday": 1, "time": "08:30", "excursion_date": "2025-01-20" }
Старый формат:
{ "excursion_id": 123, "seat_numbers": [1, 2], "passenger_type": "adult", "customer_name": "Иван Иванов", "customer_phone": "+7 (999) 123-45-67", "stop_id": 456, "weekday": 1, "time": "08:30", "excursion_date": "2025-01-20" }
GET /api/bookings/{id}/ticket-pdf
Генерация PDF билета
Требуется аутентификация

Query параметры:

Параметр Тип Описание
ids[] array Массив ID бронирований для объединения в один билет

Пример:

GET /api/bookings/123/ticket-pdf?ids[]=123&ids[]=124
DELETE /api/bookings/{id}
Отмена бронирования
Требуется аутентификация

Тело запроса:

{ "reason": "Причина отмены" }
GET /api/bookings/driver
Бронирования для водителя/экскурсовода
Требуется аутентификация
PUT /api/bookings/{id}/status
